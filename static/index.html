What do these controls mean?

Hidden units set model capacity; more is not always better. An epoch visits every training sample once. A batch averages gradients from a subset before one update.

Learning rate scales each update. SGD often needs more epochs or a larger rate than Adam. High rates can oscillate; ReLU units can stop learning if always negative.

Seed fixes data, split, initial weights, and batch order. Try changing one control at a time.

Honest scope: synthetic binary classification, one hidden layer, CPU training. No autograd, GPU, Pandas, Matplotlib, or Jupyter required.

Learn by changing one thing.

Start with the defaults, then compare SGD, a different activation, or the circular dataset. Results arrive together when training completes; these are measured metrics, not a simulated animation.
